How the rules work

  • AND: every course in allOf must be completed.
  • OR: at least one course in anyOf must be completed.
  • Program choice: COP2360 or COP2800 satisfies the programming-language choice. Selecting one disables the other and displays a note.
  • Electives: the program guide says to choose three courses from the elective list.

The COP2360 course description lists COP1000 as its prerequisite. The guide lists C# and Java as alternatives. Other course prerequisites are not assumed here; check current course descriptions.
