Making My Website Mobile Ready

This assignment updates my COP4813 homepage so it can be viewed on desktop computers, tablets, and mobile phones while keeping the same content and navigation choices.

Mobile Website Changes

I kept the existing website design and used responsive CSS so the same homepage can adjust to different screen sizes. The layout changes when the screen becomes narrower instead of sending visitors to a separate mobile page.

  • The viewport is set so the page uses the device's actual screen width.
  • The navigation links display in a two-column layout on smaller screens and become one column on very narrow screens.
  • Navigation links have larger touch areas so they are easier to select on a phone.
  • The homepage content and mascot image resize to fit the available width.
  • Cards and other multi-column areas change to a single-column layout on mobile.
  • Tables and interactive areas can scroll or resize instead of forcing the entire page wider than the screen.
  • The existing navigation links remain ordinary links, so tapping a menu item works like clicking it with a mouse.

Testing the Mobile Layout

The homepage should be checked at mobile and desktop sizes using Chrome DevTools device emulation. I will also open the published site on a phone, if available, to check the menu, image, and page layout.
