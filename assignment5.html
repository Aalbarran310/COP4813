Canvas Spirograph

This page uses JavaScript and the HTML5 canvas to draw a Spirograph from the required mathematical equations.

Spirograph Equation

The pen position is calculated from the outer circle radius R, inner circle radius r, pen offset O, and the changing value of t.

x = (R + r) cos(t) − (r + O) cos(((R + r) / r)t)
y = (R + r) sin(t) − (r + O) sin(((R + r) / r)t)

Change the values below and select Start Spirograph to draw a new pattern.

Spirograph Settings

Use positive values for R and r. The pen offset O can be zero or greater.

20 to 400
5 to 200 and less than R
0 to 250
