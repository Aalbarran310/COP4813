Assignment 6 uses an external JSON file named myjson.json.
The JavaScript on assignment6.html reads the JSON data and displays
the player information in a formatted table.

The JSON data includes sample basketball player information:
- Player name
- Team
- Season
- Games
- Scoring

For local testing on a Mac, use Start Assignment 6.command to run the
page through a local web server. Opening assignment6.html directly
from a file:// address will not load the external JSON file because
of browser security restrictions.
