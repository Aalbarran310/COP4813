ASSIGNMENT 6 - JSON
==================================================

Assignment 6 focused on using an external JSON file with JavaScript.

The player information is stored separately in:
- myjson.json

The JavaScript on assignment6.html reads the JSON data, parses it,
and displays the information in a formatted basketball scoring table.

The JSON data contains:
- Player name
- Team
- Season
- Games
- Scoring

The sample data includes basketball player records for the 2024-2025
and 2025-2026 seasons.

Files:
- assignment6.html
- myjson.json

Important:
Because assignment6.html loads an external JSON file, it should be
tested through a local web server or through the website rather than
opening the HTML file directly with a file:// address.


==================================================
ASSIGNMENT 7 - DRAG AND DROP
==================================================

Assignment 7 focuses on using JavaScript and HTML5 to implement a
drag-and-drop interface.

The assignment demonstrates:
1. Creating/displaying images
2. Dragging an image/card to another location
3. Capturing the drop event
4. Showing the user that the event occurred

The project uses a standard 52-card deck.

The Assignment 7 interface includes:
- A "Deal 5 Cards" button
- A "Reset" button
- A five-card hand
- A visible Discard Pile
- Drag-and-drop cards
- A captured drop event
- A status message confirming the discarded card
- An automatically dealt replacement card
- A shuffled deck so the same card is not dealt twice during a hand

The 52 card images are stored locally in the:
- cards/

folder.

Assignment 7 files:
- assignment7.html
- assignment7.js
- style.css
- cards/ (52 card images)
